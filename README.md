# MapleStory 2 Metadata Seeder for Redis

This repository is a side-project that seeds a Redis database with metadata for a MapleStory 2 Server Emulator written in Elixir.

The main emulator project is [sgessa/Ms2Ex](https://github.com/sgessa/ms2ex).

The metadata is originally generated by another emulator written in C#, [AlanMorel/MapleServer2](https://github.com/AlanMorel/MapleServer2), which seeds a MySQL database during its setup.

This project migrates that metadata into a Redis database for use with the **Ms2Ex** emulator.

### Purpose
The goal of this project is to extract metadata from the MySQL database used by the **MapleServer2** emulator and transform it into a format suitable for storage in Redis, enabling the **Ms2Ex** emulator to access the metadata efficiently.

### Features
- Migrates metadata from MySQL (MapleServer2) to Redis.
- Compatible with the MS2EX emulator.
- Written in [Elixir](https://github.com/elixir-lang/elixir) for seamless integration with the main emulator.

### Prerequisites
- Elixir >= 1.17
- Redis
- MySQL Server
- Access to a MySQL database seeded by MapleServer2

### Installation
Setup the MapleServer2 repository according to [documentation](https://mapleme.me/docs/setup/database-setup):
```
git clone https://github.com/AlanMorel/MapleServer2
```

Setup **Ms2Ex.File**:
```
git clone https://github.com/icr4/ms2ex_file
cd ms2ex_file
mix deps.get
```

Run setup:
```
MYSQL_URI="your_mysql_uri" REDIS_URI="your_redis_uri" mix file.setup
```

Ensure the MySQL database from MapleServer2 is running and populated.

Start Redis locally or connect to a remote instance.
